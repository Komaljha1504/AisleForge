## Defects found by failure injection

| Found by         | Defect                                                                                                | Status                                                                                                                                                                                                                                                                                                   |
| ---------------- | ----------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| K5 (E3/E1), kind | Worker process dies natively (Windows `0xC0000005`; Linux SIGSEGV 139 at every fresh kind deployment) | **Fixed (D-K5), 2026-11-23.** gdb: an Admin `ListConsumerGroupOffsets` response → `rd_kafka_cgrp_op` on a client without a consumer group. The worker no longer calls it, and also releases Kafka clients before exiting. Reproduction: 12/12 iterations crashed before, 0/10 after. See the D-K5 report |
| K5 harness       | Test lost a worker's final stderr; pino async logging lost final lines                                | Fixed                                                                                                                                                                                                                                                                                                    |
| Official run 2   | OneDrive memory leak starved the machine (environment)                                                | Mitigated: test I/O moved to `%TEMP%`                                                                                                                                                                                                                                                                    |
| K3 run 2         | Test race between the dead-letter row and its DLT stamp                                               | Fixed (test)                                                                                                                                                                                                                                                                                             |
| E3 on Compose    | nginx kept the old API IP after an API restart → 502 for every API call                               | Fixed (re-resolving upstream), verified with a forced IP change                                                                                                                                                                                                                                          |
| e2e (E9)         | Offline sign-out left the session restorable for the next person on the device                        | Fixed, verified in Chromium                                                                                                                                                                                                                                                                              |
| e2e              | Worker could sit without partition assignment after creating topics (metadata race)                   | Fixed (wait for topic metadata)                                                                                                                                                                                                                                                                          |

## Not executed (honest gaps)

- **E5 latency injection** (no Toxiproxy or `tc` on this machine).
- **E6 replica kill under load on Compose** (single replica).
- **E7 real network partition.**
- All runbook durations were shortened (seconds, not 5 minutes) to fit the time budget. The behaviour being tested
  does not depend on the duration, but backlog sizes do.
